要让你写的这个 Shell 脚本像内置命令一样在 **任何目录下都能使用**，你可以将它放到系统的 **PATH 路径中**，或者通过 `alias` 注册一个快捷命令。下面是两种推荐方式：

---

## ✅ 方法一：将脚本安装为全局命令（推荐）

### 步骤 1：给脚本命名并保存

比如你将脚本保存为：

```bash
~/scripts/rename_md.sh
```

确保它有执行权限：

```bash
chmod +x ~/scripts/rename_md.sh
```

---

### 步骤 2：将目录加入 PATH

你可以把 `~/scripts/` 加入你的 PATH 环境变量中。

#### 对于 zsh 用户（macOS 默认用 zsh）：

编辑你的 `~/.zshrc` 文件：

```bash
nano ~/.zshrc
```

添加一行：

```bash
export PATH="$HOME/scripts:$PATH"
```

保存并执行：

```bash
source ~/.zshrc
```

---

### 步骤 3：重命名脚本为简短命令（可选）

你可以将脚本命名为更简洁的名字，例如：

```bash
mv ~/scripts/rename_md.sh ~/scripts/mdrename
```

现在你就可以在任何目录下运行：

```bash
mdrename --recursive --force
```

---

## ✅ 方法二：通过 alias 添加到 zshrc（快捷方式）

如果你不想修改 PATH，可以直接在 `~/.zshrc` 中添加一个别名：

```bash
alias mdrename="bash ~/scripts/rename_md.sh"
```

然后刷新配置：

```bash
source ~/.zshrc
```

现在你可以使用：

```bash
mdrename --recursive --force
```

> ⚠️ 注意：如果你用 alias 的方式，路径不能变动，否则命令会失效。

---

## ✅ 验证是否生效

在任意目录下输入：

```bash
mdrename --help
```

如果你在脚本中没有添加 `--help` 参数，可以加一个简单帮助提示：

```bash
# 在 rename_md.sh 文件开头加入：
if [[ "$1" == "--help" ]]; then
  echo "用法: mdrename [--force] [--recursive]"
  exit 0
fi
```

## ✅ 总结

| 方法        | 优点                   | 缺点                         |
| ----------- | ---------------------- | ---------------------------- |
| 添加到 PATH | 可以像系统命令一样使用 | 需要管理 PATH                |
| 使用 alias  | 快速方便               | 路径不能变动，不能传参复杂化 |

---

## 🧠 为什么加入 PATH 后，脚本可以直接用文件名执行？

当你在终端中输入一个命令（比如 `mdrename`），**Shell（如 zsh/bash）会在一系列目录中查找这个命令对应的可执行文件**。这些目录就是你环境变量中的 `PATH`。

---

### ✅ 什么是 PATH？

`PATH` 是一个环境变量，里面存储着一组路径，Shell 会在这些路径中依次查找你输入的命令。

你可以通过命令查看当前的 PATH：

```bash
echo $PATH
```

输出类似：

```
/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin:/Users/yourname/scripts
```

这表示：

- 当你输入一个命令，比如 `mdrename`
- Shell 会依次去这些目录中查找是否有一个叫 `mdrename` 的可执行文件

---

### ✅ 举个例子

你有一个脚本：

```bash
~/scripts/mdrename
```

你做了两件事：

1. 给它加了执行权限：

   ```bash
   chmod +x ~/scripts/mdrename
   ```

2. 把 `~/scripts` 加入了 PATH：

   ```bash
   export PATH="$HOME/scripts:$PATH"
   ```

现在，当你输入：

```bash
mdrename
```

Shell 的查找流程是这样的：

1. 在 `/usr/local/bin` 找有没有 `mdrename`
2. 没有 → 去 `/usr/bin` 找
3. 没有 → 去 `/bin` 找
4. 没有 → 去你刚加的 `~/scripts` 找
5. 找到了 `~/scripts/mdrename`，并且它是可执行的 ✅
6. 执行它！

---

### ✅ 如果不在 PATH，会怎样？

如果你没有把脚本所在目录加入 PATH，Shell 就找不到这个命令，报错：

```bash
zsh: command not found: mdrename
```

你只能这样运行它：

```bash
~/scripts/mdrename
```

或者：

```bash
./mdrename     # 当前目录下
```

---

## ✅ 总结一句话：

> 把目录加入 PATH，相当于告诉系统：“这些目录里的文件我想当作命令来用”。只要文件有执行权限，Shell 就能像运行内置命令一样运行它们。
