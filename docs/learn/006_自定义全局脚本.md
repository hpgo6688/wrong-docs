要让你写的这个 Shell 脚本像内置命令一样在 **任何目录下都能使用**，你可以将它放到系统的 **PATH 路径中**，或者通过 `alias` 注册一个快捷命令。下面是两种推荐方式：

---

## ✅ 方法一：将脚本安装为全局命令（推荐）

### 步骤 1：给脚本命名并保存

比如你将脚本保存为：

```bash
~/scripts/rename_md.sh
```

确保它有执行权限：

```bash
chmod +x ~/scripts/rename_md.sh
```

---

### 步骤 2：将目录加入 PATH

你可以把 `~/scripts/` 加入你的 PATH 环境变量中。

#### 对于 zsh 用户（macOS 默认用 zsh）：

编辑你的 `~/.zshrc` 文件：

```bash
nano ~/.zshrc
```

添加一行：

```bash
export PATH="$HOME/scripts:$PATH"
```

保存并执行：

```bash
source ~/.zshrc
```

---

### 步骤 3：重命名脚本为简短命令（可选）

你可以将脚本命名为更简洁的名字，例如：

```bash
mv ~/scripts/rename_md.sh ~/scripts/mdrename
```

现在你就可以在任何目录下运行：

```bash
mdrename --recursive --force
```

---

## ✅ 方法二：通过 alias 添加到 zshrc（快捷方式）

如果你不想修改 PATH，可以直接在 `~/.zshrc` 中添加一个别名：

```bash
alias mdrename="bash ~/scripts/rename_md.sh"
```

然后刷新配置：

```bash
source ~/.zshrc
```

现在你可以使用：

```bash
mdrename --recursive --force
```

> ⚠️ 注意：如果你用 alias 的方式，路径不能变动，否则命令会失效。

---

## ✅ 验证是否生效

在任意目录下输入：

```bash
mdrename --help
```

如果你在脚本中没有添加 `--help` 参数，可以加一个简单帮助提示：

```bash
# 在 rename_md.sh 文件开头加入：
if [[ "$1" == "--help" ]]; then
  echo "用法: mdrename [--force] [--recursive]"
  exit 0
fi
```

## 为什么加入了，就能以文件名直接使用脚本？


这是一个非常好的问题！我们来深入解释一下：

---

## 🧠 为什么加入 PATH 后，脚本可以直接用文件名执行？

当你在终端中输入一个命令（比如 `mdrename`），**Shell（如 zsh/bash）会在一系列目录中查找这个命令对应的可执行文件**。这些目录就是你环境变量中的 `PATH`。

---

### ✅ 什么是 PATH？

`PATH` 是一个环境变量，里面存储着一组路径，Shell 会在这些路径中依次查找你输入的命令。

你可以通过命令查看当前的 PATH：

```bash
echo $PATH
```

输出类似：

```
/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin:/Users/yourname/scripts
```

这表示：

- 当你输入一个命令，比如 `mdrename`
- Shell 会依次去这些目录中查找是否有一个叫 `mdrename` 的可执行文件

---

### ✅ 举个例子

你有一个脚本：

```bash
~/scripts/mdrename
```

你做了两件事：

1. 给它加了执行权限：

   ```bash
   chmod +x ~/scripts/mdrename
   ```

2. 把 `~/scripts` 加入了 PATH：

   ```bash
   export PATH="$HOME/scripts:$PATH"
   ```

现在，当你输入：

```bash
mdrename
```

Shell 的查找流程是这样的：

1. 在 `/usr/local/bin` 找有没有 `mdrename`
2. 没有 → 去 `/usr/bin` 找
3. 没有 → 去 `/bin` 找
4. 没有 → 去你刚加的 `~/scripts` 找
5. 找到了 `~/scripts/mdrename`，并且它是可执行的 ✅
6. 执行它！

---

### ✅ 如果不在 PATH，会怎样？

如果你没有把脚本所在目录加入 PATH，Shell 就找不到这个命令，报错：

```bash
zsh: command not found: mdrename
```

你只能这样运行它：

```bash
~/scripts/mdrename
```

或者：

```bash
./mdrename     # 当前目录下
```

---

## ✅ 总结一句话：

> 把目录加入 PATH，相当于告诉系统：“这些目录里的文件我想当作命令来用”。只要文件有执行权限，Shell 就能像运行内置命令一样运行它们。

## 脚本

```sh
#!/bin/bash

# 用法说明
usage() {
  echo "用法: $0 [--force] [--recursive]"
  echo "  --force       强制重命名所有 .md 文件（包括已编号的）"
  echo "  --recursive   递归处理子目录中的 .md 文件"
  exit 1
}

# 默认参数
FORCE_RENAME=false
RECURSIVE=false
TARGET_DIR="."

# 解析参数
while [[ $# -gt 0 ]]; do
  case "$1" in
    --force)
      FORCE_RENAME=true
      shift
      ;;
    --recursive)
      RECURSIVE=true
      shift
      ;;
    -*)
      echo "未知参数: $1"
      usage
      ;;
    *)
      TARGET_DIR="$1"
      shift
      ;;
  esac
done

# 检查目标目录是否存在
if [ ! -d "$TARGET_DIR" ]; then
  echo "❌ 错误: 目录 '$TARGET_DIR' 不存在"
  exit 1
fi

# 切换到目标目录
cd "$TARGET_DIR" || exit 1

# 获取待处理的目录列表
if $RECURSIVE; then
  DIRS=$(find . -type f -name "*.md" -exec dirname {} \; | sort -u)
else
  DIRS="."
fi

# 遍历每个目录
for DIR in $DIRS; do
  echo "📁 处理目录: $DIR"

  # 构建查找命令
  if $FORCE_RENAME; then
    FILES=$(find "$DIR" -maxdepth 1 -type f -name "*.md" -exec stat -f "%m %N" {} \; | sort -n)
  else
    FILES=$(find "$DIR" -maxdepth 1 -type f -name "*.md" ! -regex ".*/[0-9][0-9][0-9]_.*\.md" -exec stat -f "%m %N" {} \; | sort -n)
  fi

  COUNT=1

  while IFS= read -r LINE; do
    TIME=$(echo "$LINE" | cut -d' ' -f1)
    FILE_PATH=$(echo "$LINE" | cut -d' ' -f2-)

    BASENAME=$(basename "$FILE_PATH")
    EXT="${BASENAME##*.}"
    NAME_NO_EXT="${BASENAME%.*}"

    # 去除已有编号（如果有）
    CLEAN_NAME=$(echo "$NAME_NO_EXT" | sed -E 's/^[0-9]{3}_//')

    PREFIX=$(printf "%03d" "$COUNT")
    NEW_NAME="${PREFIX}_${CLEAN_NAME}.${EXT}"
    NEW_PATH="${DIR}/${NEW_NAME}"

    if [ "$FILE_PATH" != "$NEW_PATH" ]; then
      if [ ! -e "$NEW_PATH" ]; then
        mv "$FILE_PATH" "$NEW_PATH"
        echo "✅ 重命名: $FILE_PATH -> $NEW_PATH"
      else
        echo "⚠️  跳过: $NEW_PATH 已存在"
      fi
    else
      echo "ℹ️  已正确命名: $FILE_PATH"
    fi

    COUNT=$((COUNT + 1))
  done <<< "$FILES"

done

```

./rename_by_folder.sh --force

# 递归处理所有子目录，跳过已编号
./rename_by_folder.sh --recursive

# 递归且强制重命名所有 .md 文件
