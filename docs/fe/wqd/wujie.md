1. url 不同步。浏览器刷新 iframe url 状态丢失、后退前进按钮无法使用。

你提到的是微前端中的几个**经典痛点**，尤其是在使用 iframe 实现微前端时非常突出。我们来逐条分析 Wujie 是否解决这些问题，并对每一项做出详细说明。

## ✅ Wujie 能否解决以下问题？

---

### **1. URL 不同步问题**

> ❓ 浏览器刷新 iframe 后，子应用 URL 状态丢失，浏览器前进/后退按钮失效。

✅ **Wujie 解决了这个问题**，原理如下：

* Wujie 并不是真的用 `<iframe>`，而是使用了「iframe-like」沙箱（通过 `document.createElement`, `proxy`, `eval` + DOM 隔离实现）；
* 支持子应用 URL 与主应用同步，主应用可以通过监听 `hash` 或 `history`，对子应用做路由还原；
* 提供 `sync` 参数控制是否同步主子 URL。

👉 实际表现：

* **刷新后会恢复子应用的 URL 状态**（支持路由还原）；
* **浏览器前进/后退按钮生效**，通过主应用控制子应用的路由跳转。

🔧 示例配置：

```js
Wujie.mountApp({
  name: 'app',
  url: 'http://localhost:3001',
  el: '#app',
  sync: true  // ✅ 启用主子路由同步
})
```

---

### **2. UI 不同步 / 弹框无法全屏居中**

> ❓ 子应用弹出的遮罩层居中失败，不能响应主窗口 resize。

🟡 **Wujie部分解决了这个问题，但需你手动配合处理。**

* 由于 Wujie 的子应用运行在沙箱中（不是 iframe 真隔离），所以 **DOM 实际上是注入到主应用 DOM 中的**；
* 弹框如果是通过定位（如 `position: fixed; top: 50%`）在子应用内布局的，是可以生效的；
* **但如果遮罩层设计上假设是“全局页面”，而你只在一个容器中挂载子应用，那自然不居中**。

✅ 可选方案：

* 子应用手动将遮罩层 DOM 插入主应用 DOM（挂载在 `body`）
* 或统一使用主应用提供的弹框组件（由 props 注入）

✅ Wujie还提供 `beforeLoad`, `load`, `mounted` 等生命周期，你可以在这些阶段做 DOM hack 或弹层容器挂载。

---

### **3. 上下文隔离 / Cookie / 内存变量不共享**

> ❓ iframe 内外系统的通信困难、cookie 不共享，跨域免登难做。

✅ **Wujie很好地解决了通信问题，但 Cookie 跨域仍然依赖浏览器机制**

**通信方面：**

* Wujie 提供了 `props` 共享对象、`bus` 事件总线
* 主子应用可以共享对象引用，甚至共享 Vuex/Pinia 实例（通过桥接）
* 子应用可以通过 `window.__WUJIE.props` 访问共享数据

**cookie方面：**

* **跨子域名（如 `a.example.com` → `b.example.com`）** 时，Wujie **不能突破浏览器的 cookie 同源策略**，这和 iframe 一样。
* ✅ 但你可以通过**主应用中转登录状态**或使用 `localStorage + token` 来实现“看似免登”的体验。

📝 小结：

* ✅ 内存变量共享：**支持**
* ✅ 通信同步：**支持**
* ❌ cookie 根域名不同：**无法直接透传，但可绕过**

---

### **4. 每次进入都重新加载 / 重建上下文**

> ❓ iframe 每次切换都重新渲染，性能差。

✅ **Wujie完美解决了这个问题：支持子应用“保活”**

* 子应用首次加载后，Wujie 默认**缓存了其 DOM 和运行上下文**
* 下次再进入时，Wujie 只做“挂载/显示”，不再重新下载和构建运行时
* 与 iframe 相比，**切换速度快非常多（无需重建 JS 执行环境）**

🔧 示例：

```js
Wujie.mountApp({
  name: "subapp",
  url: "http://localhost:3001",
  el: "#container",
  alive: true  // ✅ 启用保活
})
```

## ✅ 总结表格

| 问题                      | Wujie 是否解决                                | 说明 |
| ------------------------- | --------------------------------------------- | ---- |
| 1. URL 状态同步           | ✅ 支持 `sync` 参数，刷新/前进/后退无影响      |      |
| 2. UI 弹层居中问题        | 🟡 结构上支持，但需合理设计弹层挂载位置        |      |
| 3. 内存变量、通信、cookie | 🟡 内存支持，通信支持，cookie 跨域无法原生透传 |      |
| 4. 性能问题（重加载）     | ✅ 支持子应用保活，切换无感加载                |      |

---

## ✅ 总结建议

如果你希望规避 iframe 带来的典型问题，如：

* 无法通信
* 无法共享状态
* 无法保活
* 无法配合路由

那 ✅ **Wujie 是当前解决这些痛点最成熟的一种轻量微前端框架。**
