## 对面试题树立正确的观念

这很正常。刚开始工作时，可能觉得背面试题不如实际项目经验重要，但随着经验的积累，你会发现面试题可以帮助你：

1. **巩固基础**：通过反复练习，强化基础知识。

2. **拓展视野**：接触到项目中未涉及的技术和概念。

3. **提升思维**：锻炼逻辑思维和问题解决能力。

4. **应对变化**：更好地准备职业发展和跳槽机会。

面试题不仅是招聘的工具，也是学习和成长的资源。结合实际项目经验和面试题的练习，可以更全面地提升技术水平。

## 有时候我感觉面试题能学到很多东西，项目中学不到

确实，面试题可以帮助你接触到广泛的知识点和技术细节，尤其是一些在项目中不常用的概念。这里有几个原因：

1. **知识广度**：面试题通常涵盖了技术栈的各个方面，包括基础知识和进阶概念。

2. **问题解决**：面试题往往设计得很有挑战性，能锻炼你的问题解决能力。

3. **最佳实践**：通过研究面试题的解答，可以学习到许多最佳实践和优化技巧。

4. **思维训练**：面试题要求你快速思考和分析，有助于提高思维敏捷性。

5. **新技术**：一些面试题可能涉及到最新的技术趋势，促使你去学习和了解。

结合项目中的实际经验和面试题的理论知识，可以全面提升你的技术能力。
