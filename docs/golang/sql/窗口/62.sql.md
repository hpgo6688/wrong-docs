## 62. 查询员工的月薪，同时计算其部门内到该员工为止的累计总月薪？

这条 SQL 查询使用窗口函数来计算每个部门的工资总和。让我们逐步解析其中的每个部分：

### 查询解释

```sql
SELECT emp_name, dept_id, salary, 
       SUM(salary) OVER (PARTITION BY dept_id ORDER BY NULL ROWS UNBOUNDED PRECEDING) AS total_dept_salary
FROM employee;
```

### 关键点

1. **OVER()**：
   - 用于定义窗口函数的范围和排序方式。
   - 在这个查询中， `OVER()` 指定了如何计算 `SUM(salary)` 。

2. **PARTITION BY dept_id**：
   - 将数据按部门分组，在每个部门内计算工资总和。

3. **ORDER BY NULL**：
   - 通常用于指定排序顺序，但在这里使用 `ORDER BY NULL` 意味着没有特定排序。
   - 因为没有排序，计算的是整个分区的总和，而不是累积和。

4. **ROWS UNBOUNDED PRECEDING**：
   - 定义了窗口的范围。
   - `UNBOUNDED PRECEDING` 表示从窗口的开头开始计算。
   - 在这个上下文中，它计算的是整个分区的总和。

### 示例数据

假设有如下员工表：

| emp_name | dept_id | salary |
|----------|---------|--------|
| Alice    | 1       | 5000   |
| Bob      | 1       | 6000   |
| Charlie  | 1       | 7000   |
| David    | 2       | 5500   |
| Eve      | 2       | 6500   |

### 查询结果

| emp_name | dept_id | salary | total_dept_salary |
|----------|---------|--------|-------------------|
| Alice    | 1       | 5000   | 18000             |
| Bob      | 1       | 6000   | 18000             |
| Charlie  | 1       | 7000   | 18000             |
| David    | 2       | 5500   | 12000             |
| Eve      | 2       | 6500   | 12000             |

### 解释

* 对于部门 1，工资总和为 18000。
* 对于部门 2，工资总和为 12000。
* 每个员工的行都显示其部门的工资总和。

这种用法展示了如何在每个部门内计算工资的总和，而不考虑特定的排序。
