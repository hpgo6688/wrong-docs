## 63. 查询员工的月薪，同时计算其部门内按照月薪排序后，前一个员工、当前员工以及后一个员工的平均月薪？

这条 SQL 查询使用窗口函数来计算每个员工在其部门内的工资的移动平均值。让我们解析一下关键部分：

### 查询解释

```sql
SELECT emp_name, dept_id, salary, 
       AVG(salary) OVER (PARTITION BY dept_id ORDER BY salary ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING) AS moving_avg
FROM employee;
```

### 关键点

1. **OVER()**：
   - 定义了窗口函数的范围和排序方式。

2. **PARTITION BY dept_id**：
   - 将数据按部门分组，在每个部门内计算。

3. **ORDER BY salary**：
   - 按照工资排序，计算移动平均值。

4. **ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING**：
   - 定义了窗口的范围。
   - `1 PRECEDING` 表示包括当前行之前的一行。
   - `1 FOLLOWING` 表示包括当前行之后的一行。
   - 因此，计算的是当前行及其前后各一行的平均值。

### 示例数据

假设有如下员工表：

| emp_name | dept_id | salary |
|----------|---------|--------|
| Alice    | 1       | 5000   |
| Bob      | 1       | 6000   |
| Charlie  | 1       | 7000   |
| David    | 2       | 5500   |
| Eve      | 2       | 6500   |

### 查询结果

| emp_name | dept_id | salary | moving_avg |
|----------|---------|--------|------------|
| Alice    | 1       | 5000   | 5500       |
| Bob      | 1       | 6000   | 6000       |
| Charlie  | 1       | 7000   | 6500       |
| David    | 2       | 5500   | 6000       |
| Eve      | 2       | 6500   | 6000       |

### 解释

* **Alice**：平均值是 (5000 + 6000) / 2 = 5500，因为前面没有行。
* **Bob**：平均值是 (5000 + 6000 + 7000) / 3 = 6000。
* **Charlie**：平均值是 (6000 + 7000) / 2 = 6500，因为后面没有行。
* **David** 和 **Eve**：类似地计算。

这种方法用于计算当前行及其周围行的平均值，适合需要局部平滑数据的场景。
