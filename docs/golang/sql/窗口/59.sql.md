## 59. 查询员工的月薪，同时返回该员工所在部门的平均月薪。如何使用聚合函数实现？

这条 SQL 查询的作用是计算每个员工所在部门的平均工资。让我们详细解释一下：

### 查询解释

```sql
SELECT emp_name, salary, AVG(salary) OVER (PARTITION BY dept_id) AS avg_dept_salary
FROM employee;
```

### 关键点

1. **AVG(salary) OVER (PARTITION BY dept_id)**：
   - 这是一个窗口函数，用于计算每个部门的平均工资。
   - `PARTITION BY dept_id` ：在每个部门内单独计算平均值。✅

2. **结果列**：
   - `emp_name` ：员工名字。
   - `salary` ：员工工资。
   - `avg_dept_salary` ：员工所在部门的平均工资。

### 示例数据

假设有如下员工表：

| emp_name | dept_id | salary |
|----------|---------|--------|
| Alice    | 1       | 5000   |
| Bob      | 1       | 6000   |
| Charlie  | 1       | 7000   |
| David    | 2       | 5500   |
| Eve      | 2       | 6500   |

### 查询结果

| emp_name | salary | avg_dept_salary |
|----------|--------|-----------------|
| Alice    | 5000   | 6000            |
| Bob      | 6000   | 6000            |
| Charlie  | 7000   | 6000            |
| David    | 5500   | 6000            |
| Eve      | 6500   | 6000            |

### 解释

* 对于部门 1，员工的工资分别是 5000、6000 和 7000，平均工资是 6000。
* 对于部门 2，员工的工资分别是 5500 和 6500，平均工资是 6000。

每个员工所在行都会显示其部门的平均工资。这样可以让你看到每个员工的工资与其部门平均水平的对比。
