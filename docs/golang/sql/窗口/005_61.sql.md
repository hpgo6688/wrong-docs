61. 查询员工的入职日期，同时计算其部门内在该员工之前一个和之后一个入职的员工？

### 查询解释

```sql
SELECT emp_name, dept_id, hire_date,
       LAG(emp_name, 1) OVER (PARTITION BY dept_id ORDER BY hire_date) AS prev_emp,
       LEAD(emp_name, 1) OVER (PARTITION BY dept_id ORDER BY hire_date) AS next_emp
FROM employee;
```

### 关键点

01. **窗口函数**：
   - `LAG(emp_name, 1) OVER (PARTITION BY dept_id ORDER BY hire_date) AS prev_emp` ：

     - 获取当前员工在同一部门中按入职日期排序的前一位员工名字。

   - `LEAD(emp_name, 1) OVER (PARTITION BY dept_id ORDER BY hire_date) AS next_emp` ：

     - 获取当前员工在同一部门中按入职日期排序的后一位员工名字。

02. **分组与排序**：
   - `PARTITION BY dept_id` ：在每个部门内单独处理。
   - `ORDER BY hire_date` ：在每个部门内按入职日期排序。

### 查询结果示例

假设我们有一个如下的员工表：

| emp_name | dept_id | hire_date  |
|----------|---------|------------|
| Alice    | 1       | 2022-01-01 |
| Bob      | 1       | 2022-02-01 |
| Charlie  | 1       | 2022-03-01 |
| David    | 2       | 2022-01-15 |
| Eve      | 2       | 2022-02-15 |

### 结果

| emp_name | dept_id | hire_date  | prev_emp | next_emp |
|----------|---------|------------|----------|----------|
| Alice    | 1       | 2022-01-01 | NULL     | Bob      |
| Bob      | 1       | 2022-02-01 | Alice    | Charlie  |
| Charlie  | 1       | 2022-03-01 | Bob      | NULL     |
| David    | 2       | 2022-01-15 | NULL     | Eve      |
| Eve      | 2       | 2022-02-15 | David    | NULL     |

### 解释

* **Alice** 在部门 1 是第一个入职的，所以 `prev_emp` 为 `NULL`，`next_emp` 是 `Bob`。
* **Bob** 的 `prev_emp` 是 `Alice`，`next_emp` 是 `Charlie`。
* **Charlie** 是部门 1 中最后一个入职的，所以 `next_emp` 为 `NULL`。
* **David** 在部门 2 是第一个入职的，`next_emp` 是 `Eve`。
* **Eve** 是部门 2 中最后一个入职的，所以 `next_emp` 为 `NULL`。
