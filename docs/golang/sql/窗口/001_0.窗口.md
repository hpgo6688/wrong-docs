### 什么是窗口？

在 SQL 中，窗口函数允许你在一个特定的“窗口”内进行计算。这个窗口是指一组行，它们的范围可以通过 `PARTITION BY` 和 `ORDER BY` 以及 `ROWS` 或 `RANGE` 子句来定义。

✅ 在数据的特定部分上执行计算

### 关键组件

1. **PARTITION BY**：
   - 将数据分成不同的组，每组内独立计算。
   - 类似于 `GROUP BY` ，但不会减少结果集的行数。

2. **ORDER BY**：
   - 在每个分区内对数据进行排序。
   - 排序决定了窗口内行的相对位置。

3. **ROWS BETWEEN ... AND ...**：
   - 定义窗口的具体范围。
   - `1 PRECEDING` 和 `1 FOLLOWING` 指定了窗口包括当前行的前一行和后一行。

### 示例解释

考虑一个有序的部门内员工工资表：

| emp_name | dept_id | salary |
|----------|---------|--------|
| Alice    | 1       | 5000   |
| Bob      | 1       | 6000   |
| Charlie  | 1       | 7000   |

对于 **Bob**：

* **窗口范围**：包括 **Alice**（前一行）、**Bob**（当前行）、和 **Charlie**（后一行）。
* **计算**：在这个窗口内（5000, 6000, 7000），计算平均工资。

### 为什么使用窗口？

* **灵活性**：窗口函数可以在不减少行数的情况下进行计算。
* **局部计算**：能够在数据的局部范围内进行聚合或分析，如移动平均、排名等。

### 总结

窗口函数提供了一种强大的方法来在数据的子集上进行复杂的分析，而不需要改变原始数据的结构。通过定义“窗口”的范围，你可以在数据的特定部分上执行计算。
