CSS Grid 提供了一系列强大的属性，用于创建复杂的网格布局。以下是一些常用的 CSS Grid 属性及其作用：

### 容器属性

01. **`display: grid;`** 或 **`display: inline-grid;`**
   - 定义一个元素为网格容器。

02. **`grid-template-columns`**
   - 定义列的宽度和数量。

03. **`grid-template-rows`**
   - 定义行的高度和数量。

04. **`grid-template-areas`**
   - 使用命名区域来定义布局。

05. **`grid-template`**
   - 简写属性，用于同时定义行、列和区域。

06. **`grid-column-gap`** / **`column-gap`**
   - 定义列之间的间距。

07. **`grid-row-gap`** / **`row-gap`**
   - 定义行之间的间距。

08. **`grid-gap`** / **`gap`**
   - 简写属性，用于同时定义行和列的间距。

09. **`justify-items`**
   - 定义网格项在单元格内的水平对齐方式。

10. **`align-items`**
    - 定义网格项在单元格内的垂直对齐方式。

11. **`place-items`**
    - 简写属性，用于同时定义水平和垂直对齐方式。

12. **`justify-content`**
    - 定义整个内容区域在容器内的水平对齐方式。

13. **`align-content`**
    - 定义整个内容区域在容器内的垂直对齐方式。

14. **`place-content`**
    - 简写属性，用于同时定义水平和垂直对齐方式。

15. **`grid-auto-columns`**
    - 定义自动生成的列的宽度。

16. **`grid-auto-rows`**
    - 定义自动生成的行的高度。

17. **`grid-auto-flow`**
    - 控制自动布局算法的方向。

### 项目属性

01. **`grid-column-start`**
   - 定义项目的起始列位置。

02. **`grid-column-end`**
   - 定义项目的结束列位置。

03. **`grid-row-start`**
   - 定义项目的起始行位置。

04. **`grid-row-end`**
   - 定义项目的结束行位置。

05. **`grid-column`**
   - 简写属性，用于同时定义起始和结束列。

06. **`grid-row`**
   - 简写属性，用于同时定义起始和结束行。

07. **`grid-area`**
   - 定义项目所在的区域，或用于命名区域。

08. **`justify-self`**
   - 定义项目在单元格内的水平对齐方式。

09. **`align-self`**
   - 定义项目在单元格内的垂直对齐方式。

10. **`place-self`**
    - 简写属性，用于同时定义水平和垂直对齐方式。

这些属性可以组合使用，创建灵活和响应式的布局。
